## 🚀 Quick Start (Local Setup)

### Prerequisites
* Docker & Docker Compose
* Python 3.12+
* Node.js 20+

### Step 1: Clone & Configure
```bash
cp .env.example .env
```

### Step 2: Run Services with Docker Compose
```bash
docker-compose up --build
```

### Step 3: Run Tests
```bash
pytest tests/
```
